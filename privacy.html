Политика конфиденциальности

Дата обновления: 28 июля 2026 г.

Настоящая Политика описывает, какие данные обрабатываются при использовании Telegram Mini App (далее — «Приложение»), связанного с партнёрскими предложениями онлайн-казино, и как эти данные используются.

1. Оператор данных

Оператором данных, собираемых через Приложение, является владелец данного Telegram Mini App / партнёрского проекта. По вопросам обработки данных обращайтесь через Telegram-бот или контакт, указанный в описании Приложения.

2. Какие данные мы обрабатываем

В зависимости от сценария использования могут обрабатываться:

  • идентификатор пользователя Telegram (user id);
  • имя и username в Telegram (если доступны через Telegram WebApp API);
  • параметр запуска (start_param) — источник перехода;
  • тип устройства / платформа (iOS, Android, Desktop и т.п.);
  • приблизительные геоданные (страна, город) на основе IP-адреса;
  • события взаимодействия с Приложением: открытие, клики по кнопкам, копирование промокода, уход со страницы, время на странице;
  • технические данные, необходимые для работы ссылок и атрибуции (в том числе sub-параметры партнёрской ссылки);
  • данные о событиях на стороне партнёрского казино (регистрация, депозит и др.), если партнёрская программа передаёт постбэки с идентификаторами атрибуции.

Мы не запрашиваем и не храним пароли, данные банковских карт и иные платёжные реквизиты через Приложение.

3. Цели обработки

  • работа Приложения и корректный переход на партнёрские ресурсы;
  • аналитика воронки (открытия, клики, конверсии);
  • атрибуция трафика и оценка эффективности источников;
  • улучшение интерфейса и офферов;
  • предотвращение злоупотреблений и техническая безопасность.

4. Источники данных

  • Telegram WebApp API (данные пользователя и параметры запуска);
  • действия пользователя внутри Приложения;
  • IP-геолокация через сторонний сервис определения страны/города по IP;
  • постбэки партнёрской программы казино (при настройке такой интеграции).

5. Передача данных третьим лицам

Данные могут обрабатываться с использованием:

  • инфраструктуры Google (Google Sheets / Google Apps Script) — для хранения и обработки событий аналитики;
  • партнёрской платформы / оператора казино — в объёме, необходимом для атрибуции переходов, регистраций и депозитов (например, sub-идентификаторы);
  • сервиса IP-геолокации — для определения приблизительного региона.

Мы не продаём персональные данные пользователей третьим лицам в маркетинговых целях.

6. Срок хранения

Данные хранятся столько, сколько необходимо для целей аналитики и атрибуции, как правило не дольше 12 месяцев с даты последнего события, если иной срок не требуется по закону или для защиты законных интересов.

7. Ваши права

В пределах применимого права вы можете запросить:

  • информацию об обрабатываемых данных;
  • исправление неточных данных;
  • удаление данных (если нет законных оснований для дальнейшего хранения);
  • ограничение обработки.

Для запроса свяжитесь с оператором через Telegram-бот / контакт в описании Приложения. Укажите Telegram user id и суть запроса.

8. Возрастные ограничения

Приложение предназначено только для лиц старше 18 лет. Онлайн-азартные игры доступны исключительно совершеннолетним пользователям в соответствии с законодательством их страны.

9. Сторонние ресурсы

При переходе по кнопкам Приложения вы можете попасть на сайты партнёров (в том числе онлайн-казино). Обработка данных на таких сайтах регулируется их собственными политиками конфиденциальности и правилами.

10. Изменения политики

Мы можем обновлять текст Политики. Актуальная версия всегда доступна на этой странице. Дата последнего обновления указана в начале документа.

11. Контакты

По вопросам, связанным с персональными данными, обращайтесь через официальный Telegram-бот или контакт, указанный в описании Mini App.

Документ носит информационный характер и не заменяет юридическую консультацию. Требования зависят от вашей юрисдикции и юрисдикции пользователей.
